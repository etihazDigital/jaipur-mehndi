HOW TO ADD MORE PHOTOS LATER
------------------------------
To ADD a brand-new photo instead of replacing one:
  1. Pick the correct category: bridal-full-arm / bridal-hand-palm /
     mini-personalized.
  2. Name the file using the next number in that category, e.g. if
     "bridal-full-arm-20.jpg" is currently the last one, your new
     photo should be named "bridal-full-arm-21.jpg".
  3. Save it into this "assets" folder.
  4. Open "script.js" in the website folder, find the three "for"
     loops near the top (search for "bridal-full-arm-", "bridal-hand-
     palm-" or "mini-personalized-") and change the number in
     "i <= 20", "j <= 9" or "k <= 5" to match your new total count.
     (If you're not comfortable editing code, just send the new
     photos to your web developer with this file and they can do it
     in under a minute.)

FILE FORMAT TIPS
------------------
- Use .jpg photos, ideally under 500 KB each, so the site stays fast
  to load on mobile data.
- Portrait (tall) photos work best for the gallery — that's the shape
  most bridal mehandi photos naturally have.
- Keep the exact lowercase file names shown above — website links are
  case-sensitive.
